# 探検家スプライトの生成ドラフト

人型キャラクター用の `ART_STYLE.md` を基準に生成した候補画像です。
金色に近い緑のポニーテール、額のゴーグル、中性的な顔、探検家の服を指定しています。

- `explorer_idle_draft.png`: 待機、4列×8行の候補。
- `explorer_walk_draft.png`: 歩き、8列×8行の候補。
- `explorer_run_draft.png`: 走り、8列×8行の候補。

## 検査結果と未完了項目

- PNG はアルファチャンネルと透明画素を持つ。
- 生成結果は規定のシート寸法と128×128セルに一致していない。そのまま固定セルで切り出して使用しない。
- 輪郭周辺に赤・黄などの色ノイズが残っている。背景透過と輪郭の補正が必要。
- 歩きの右上方向は右向きに近く、右方向は右下に近い。方向の修正が必要。
- 待機を補正した画像と歩き・走りで髪の緑の強さに差があり、配色の統一が必要。
- 2頭身の比率、足元基準点、フレーム間の位置、手足の連続性、ループは最終調整・再検査が必要。
- Godot のアニメーション登録とメインシーンへの配置は行っていない。

これらは完成素材ではない。仕上げ時に128×128セル、所定の行順・基準点・フレーム数に揃え、背景と輪郭を検査したうえで本番用ファイルを作成する。
