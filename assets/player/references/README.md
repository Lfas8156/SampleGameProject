# 探検家の4面図

[4面図](explorer_four_view_pixel_reference.png)は、256×256 pxの透過PNGです。各向きを128×128 pxの領域に配置しています。左上が前、右上が後ろ、左下が左向き、右下が右向きです。

金色に近い緑のポニーテール、額のゴーグル、口を描かない顔、かわいい探検家の服を確認するための資料です。クリーム色のパフ袖ブラウス、茶色の短いベスト、青緑のスカート風ショートパンツ、首元のスカーフ、ポニーテールのリボンとブーツを4方向で揃えています。背中には留め具付きの茶色い革のリュックを背負っています。

つるはしは木製の柄と鉄製の先端を持つ1本です。正面では両手で柄を握り、体の前で水平に構えています。他の3方向でも同じ道具を持っています。

この4面図は外見資料です。ゲーム用の64×64 pxスプライトは[探検家スプライト](../README.md)を参照してください。
