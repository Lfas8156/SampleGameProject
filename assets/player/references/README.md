# 探検家の4面図

`explorer_four_view_pixel_reference.png` は、前・後ろ・左・右の順に並べた、低解像度ドット絵風の外見資料です。
金色に近い緑のポニーテール、額のゴーグル、口を描かない顔、かわいい探検家の服を確認するために使用します。
クリーム色のパフ袖ブラウス、茶色の短いベスト、青緑のスカート風ショートパンツ、首元のスカーフ、ポニーテールのリボン、ポーチとブーツを4方向で揃えます。
背中には留め具付きの茶色い革のリュックを背負います。後ろ姿ではリュック全体、正面では肩紐、横姿では背中側に出る厚みを示します。後ろ姿の髪は1本のポニーテールに統一します。
つるはしは木製の柄と鉄製の先端を持つ1本です。正面では両手で柄を握り、体の前で水平に構えます。他の3方向でも同じ道具・持ち方を保ちます。

この画像は生成時の大きな表示サイズのままで、厳密な48×48 pxのゲーム用スプライトではありません。細部に補間や画素サイズの不揃いが見られるため、実装時は `ART_STYLE.md` の画素数・色数・足元基準に合わせてドット単位で清書します。4面図から斜め4方向と待機・歩き・走りを制作する段階も残っています。
